# RAMCAD — архив материалов

Оригинальные вложения из обсуждения дизайна сайта от 6 октября 2026 года.

## Содержимое

- `products/originals/` — 46 изображений упаковок, без изменений.
- `screenshots/original/` — 2 исходных скриншота сайта.
- `mockups/uploaded/` — 5 вариантов макетов, которые были прикреплены пользователем повторно. Для одинакового исходного имени `generated-image.png` назначены уникальные имена.
- `manifest.json` — исходные имена, идентификаторы вложений, размеры и SHA-256 каждого файла.

Повторные отправки одного и того же вложения не дублируются. Все 53 уникальных вложения с идентификаторами файлов восстановлены.

## Полнота архива

В архив включены файлы, отправленные пользователем. Последние сгенерированные изображения (финальная светлая главная с увеличенной кнопкой, финальная тёмная главная с телефоном и каталог) не были повторно прикреплены как вложения с доступным идентификатором. Их исходные файлы сейчас недоступны; они не подменены более ранними версиями.

Этот репозиторий предназначен для закрытого хранения материалов проекта.
