# RAMCAD — архив материалов

Референсы, присланные в чат во время работы над сайтом RAMCAD (редизайн icechr.ru).

## Содержимое

- `references/icechr-hero-reference.webp` — скриншот текущего первого экрана icechr.ru, использованный как референс для хиро-блока.
- `references/nav-panel-annotation.jpg` — аннотированный скриншот сайта RAMCAD с пометкой «перенести навигацию в боковую панель».
- `references/contacts-map-annotation.jpg` — аннотированный скриншот блока «Контакты» с пометкой про видео-карту на фоне и перенос блока адреса в угол.
- `videos/karta_animation.mp4` — анимация карты (1920×1080, 14 с, H.264), используется как фон блока контактов на сайте.

## Примечание

Предыдущая версия этого README описывала более крупный архив (46 фото упаковок, 5 макетов, manifest.json) — те файлы не были обнаружены в репозитории ни в рабочем дереве, ни в истории git, ни в релизах; скорее всего, они относятся к другой сессии/обсуждению и никогда сюда не попадали. Актуальное содержимое репозитория — только четыре файла, перечисленные выше.

Этот репозиторий предназначен для закрытого хранения материалов проекта.
